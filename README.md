# CarePulse - Doctor Appointment Booking Web Application

A modern, responsive, full-featured **Doctor Appointment Booking Platform** built with semantic HTML5, CSS3, and Vanilla JavaScript.

## Features
- **4-Step Booking Wizard**:
  - Step 1: Select doctor with live search, specialty filter chips, and rating cards.
  - Step 2: Choose consultation mode (In-Clinic or Video Call), 14-day date picker carousel, and dynamic time slots.
  - Step 3: Patient intake form with real-time field validation.
  - Step 4: Summary review with quick-edit shortcuts and transparent fee billing breakdown.
- **Confirmation Pass & Print**:
  - Digital appointment pass with unique booking ID (e.g., `CP-77881`) and QR code.
  - `@media print` slip layout for physical receipts.
  - Calendar export (`.ics` file) for one-click calendar addition.
- **My Bookings & Dark Mode**:
  - Persistent appointment tracking via `localStorage`.
  - Cancel appointment functionality.
  - Clinical Light and Obsidian Dark theme toggle.

## Deployment on Render
1. Connect your GitHub repository `krishanusingh74-cell/doc` to Render.
2. Select **Static Site**.
3. Set **Publish directory** to `.`.
4. Deploy!
